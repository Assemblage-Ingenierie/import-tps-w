⚙️ Paramètres
Token Airtable
Créer un token sur airtable.com/account → Personal access tokens → Create token.
Scopes requis : data.records:read + data.records:write sur la base Assemblage.
Le token est stocké uniquement dans votre navigateur (localStorage), jamais envoyé ailleurs.
Calendrier des congés Payfit
Utilisée uniquement par le bouton de téléchargement de l'étape 1. Le fichier doit être déposé manuellement : l'API Payfit ne renvoie pas d'en-tête Access-Control-Allow-Origin, ce qui empêche toute lecture directe depuis cette page.
Configuration Airtable
Lors de l'analyse, l'app charge les tables Collaborateur et Affaire et résout les liens avant envoi. Si un collaborateur ou une affaire n'existe pas, le lien est laissé vide sans bloquer l'import.
