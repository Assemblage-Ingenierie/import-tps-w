⚙️ Paramètres
Token Airtable
Usage local uniquement. Créer un token sur airtable.com/account → Personal access tokens → Create token.
Scopes requis : data.records:read + data.records:write sur la base Assemblage.
Stocké uniquement dans votre navigateur, jamais dans le code.
En version déployée, le token Airtable est géré côté serveur (variable d'environnement AIRTABLE_TOKEN) et partagé par tous les utilisateurs autorisés — rien à saisir ici. Les appels passent par un relais qui ajoute le token sans jamais l'exposer au navigateur.
Calendrier des congés Payfit
Usage local uniquement. Sert au bouton de téléchargement de l'étape 1, avant dépôt manuel du fichier. Stockée dans votre navigateur, jamais dans le code — cette URL répond sans authentification, quiconque la détient lit les absences de toute l'entreprise.
En version déployée, le calendrier est récupéré automatiquement au chargement, via un relais côté serveur qui conserve l'URL hors du navigateur. Ce relais est nécessaire : l'API Payfit ne renvoie pas d'en-tête Access-Control-Allow-Origin, donc aucune page web ne peut l'appeler directement, quel que soit son hébergement.
Configuration Airtable
Lors de l'analyse, l'app charge les tables Collaborateur et Affaire et résout les liens avant envoi. Si un collaborateur ou une affaire n'existe pas, le lien est laissé vide sans bloquer l'import.
